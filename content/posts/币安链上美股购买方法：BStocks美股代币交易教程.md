# 一、什么是链上美股？

所谓“链上美股”，通常是指将股票或 ETF 的经济权益通过区块链代币化后，以数字资产形式提供交易或转移。

这类产品通常属于 RWA（Real World Assets）的一部分。

简单理解：

**传统股票 → 通过相关机构进行资产托管或权益安排 → 发行对应的链上代币 → 用户通过支持的平台进行交易。**

需要注意的是，**股票代币并不一定等于传统股票本身**。

例如，购买某个与英伟达股票价格挂钩的代币，并不意味着你就成为英伟达的登记股东，也不一定拥有传统股票所对应的投票权、股东大会参与权等权利。

因此，在购买之前，需要先查看发行方对于资产支持、托管、赎回、股息以及持有人权益的具体说明。

# 三、RWA 和股票代币化是什么意思？

RWA 是 **Real World Assets** 的缩写，中文通常翻译为“现实世界资产”。

传统金融中的股票、债券、基金、房地产等，都可以成为 RWA 相关应用的资产类型。

股票代币化则是把与现实资产相关的权益或经济价值，以区块链代币的形式进行表示。

例如：

**现实股票资产 → 托管/权益安排 → 代币化 → 链上交易**

这样做的一个重要意义，是让部分传统金融资产能够接入区块链基础设施。

不过需要特别注意：

**“链上交易”不代表“没有监管”，也不代表“任何地区的用户都可以购买”。**

不同产品对于用户所在地区、身份认证、钱包类型以及交易资格，都可能存在不同要求。

# 五、购买链上美股之前，需要注意什么？

## 1. 先确认地区是否支持

股票代币化产品通常存在地区限制。

不同平台的开放范围并不一样，即使某个产品可以在某个国家或地区交易，也不能推断其他地区同样开放。

因此，在注册、充值和下单之前，应先查看平台当前的地区政策。

如果平台提示所在地区无法交易，不建议通过虚假身份或其他方式绕过限制。

## 2. 注意钱包和网络

如果通过 Web3 钱包购买链上股票，需要确认股票代币运行在哪条区块链上。

例如不同产品可能分别运行在：

* Ethereum
* BNB Chain
* Solana
* Arbitrum
* Morph

不同网络对应不同的资产格式和 Gas 机制。

转账之前一定要确认**网络是否一致**，否则可能产生资产无法正常到账的问题。

## 3. 注意 Gas 费用

链上交易除了产品本身的交易费用之外，还可能涉及网络 Gas。

不同网络的 Gas 成本不同。

有些钱包提供免 Gas 或代付 Gas 功能，但具体是否支持某个产品，需要以钱包当前页面显示的规则为准。

## 4. 确认产品最低交易金额

有些股票代币支持碎股交易，因此用户不一定需要购买完整的一股股票。

但“最低 5 美元”并不是所有股票代币、所有平台都通用的规则。

具体最低下单金额应该以交易页面实际显示的数据为准。

# 八、限价单和市价单有什么区别？

进入交易页面后，一般会看到不同的订单类型。

## 市价单

市价单是按照当前市场可成交价格快速执行。

优点是操作简单、成交速度较快。

缺点是最终成交价格可能与下单时看到的价格存在一定差异，尤其是在流动性不足或者市场波动较大的情况下。

## 限价单

限价单则是由用户自己设定价格。

例如当前价格为 180 美元，你可以设置 175 美元买入。

只有市场价格达到你的条件并且有足够的对手方订单时，才可能成交。

所以：

**想立即成交，可以考虑市价单；**

**想控制成交价格，可以考虑限价单。**

具体支持哪些订单类型，以实际交易页面为准。

# 十一、链上美股和传统美股有什么区别？

两者最重要的区别，并不是“一个在网上，一个在线下”，而是**法律结构、资产所有权和交易体系不同**。

| 对比项目       | 传统美股      | 股票代币         |
| ---------- | --------- | ------------ |
| 交易方式       | 证券账户      | 交易所或 Web3 平台 |
| 资产形式       | 传统证券      | 区块链代币        |
| 是否一定拥有股票本身 | 是         | 不一定          |
| 股东投票权      | 通常存在      | 通常不等同于直接持股   |
| 交易时间       | 受证券市场规则影响 | 取决于具体产品      |
| 链上转账       | 通常不支持     | 部分产品支持       |
| 钱包管理       | 通常不是核心环节  | 部分产品需要       |
| 地区限制       | 存在        | 同样可能存在       |

因此，不应该简单理解为：

**“买股票代币 = 买了一股真正的美股。”**

实际权益需要根据发行方的产品条款判断。

# 十二、链上美股是不是 24 小时都能交易？

这是很多新用户容易误解的地方。

区块链本身可以 24 小时运行，但**股票代币产品是否能够 24/7 交易，并不只取决于区块链技术**。

发行方、交易平台、做市机制、底层资产市场以及产品规则，都可能影响实际交易时间。

因此，即使某个产品支持链上交易，也不能直接认为它一定能够在周末、节假日以及美股休市期间按照正常市场价格自由交易。

如果平台明确标注支持全天候交易，则以平台规则为准。

# 十四、链上美股安全吗？

“有真实资产支持”并不等于“没有风险”。

购买之前至少需要考虑以下几个方面：

### 1. 发行方风险

需要了解代币由谁发行，以及底层资产如何托管。

### 2. 托管风险

如果产品宣称由真实股票支持，需要查看具体托管机构以及资产证明方式。

### 3. 平台风险

交易平台本身也存在运营、技术和合规风险。

### 4. 流动性风险

链上交易的流动性可能与传统证券市场不同。

在市场剧烈波动的时候，买卖价差也可能扩大。

### 5. 价格偏离风险

股票代币通常会参考底层股票价格，但不代表任何时候都能够完全一比一成交。

### 6. 智能合约风险

如果通过区块链钱包操作，还需要考虑智能合约和区块链网络本身的技术风险。

### Q1：股票代币是真正的股票吗？

不一定。

股票代币是区块链上的代币化产品，其具体法律权益和底层资产结构需要根据发行方的产品说明判断。

购买之前不要仅凭“股票代币”这个名称，就认为自己拥有传统股票对应的全部股东权益。

### Q2：买股票代币可以获得分红吗？

这取决于具体产品的设计。

有些产品可能会通过特定机制处理股息或其他经济权益，也有些产品并不直接向代币持有人提供传统股票的分红权。

因此，应以发行方公布的产品条款为准。

### Q3：股票代币可以转到自己的钱包吗？

不一定。

部分产品支持链上转移，部分产品可能只能在特定平台内部交易。

是否支持提币、转账以及支持哪些网络，需要查看具体产品规则。

### Q4：是不是有钱包就可以买？

不是。

钱包只是技术工具。

你仍然需要满足平台的地区、身份、产品资格以及其他交易条件。

### Q5：股票跌了，股票代币也会跌吗？

如果代币的设计是跟踪对应股票价格，那么底层股票价格变化通常会影响代币价格。

但具体跟踪机制、交易时间以及价格偏离情况，需要查看产品规则。

不是。

5 美元只是部分产品可能提供的最低交易金额，具体金额会受到平台、产品和交易规则影响。
