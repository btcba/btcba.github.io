**想立即成交，可以考虑市价单；**

# 十三、AMZNB和真正的AMZN有什么区别？

这是购买之前最应该搞清楚的问题。

**AMZN** 是亚马逊在美国证券市场交易的股票代码。

**AMZNB** 则属于股票代币产品。

两者不能简单理解成完全相同的资产。

主要区别可以从几个方面理解：

| 项目          | AMZN         | AMZNB          |
| ----------- | ------------ | -------------- |
| 类型          | 美国上市公司股票     | 股票代币产品         |
| 传统股票代码      | AMZN         | AMZNB          |
| 交易渠道        | 证券市场         | 加密资产交易平台相关市场   |
| 计价方式        | 通常为美元        | 通常以平台支持的数字资产计价 |
| 是否等同于直接持有股票 | 是传统证券持仓      | 不应直接等同         |
| 交易时间        | 按证券市场规则      | 按具体产品规则        |
| 适用地区        | 受证券市场及券商规则影响 | 受产品及平台地区限制影响   |

所以，购买之前一定要先确认自己买的是**股票本身还是股票代币产品**。
