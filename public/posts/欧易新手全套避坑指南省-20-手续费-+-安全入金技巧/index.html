    三、 KYC 身份认证流程 #

    为符合国际反洗钱（AML）法规，所有合规加密货币交易所必须在出入金前完成身份认证，无法跳过。

    1. 进入账户设置，点击「身份认证」。
    2. 确认居住国选择为中国。
    3. 按照提示上传中国大陆身份证正反面照片。
    4. 完成人脸识别，等待系统审核通过即可获得完整的交易与出入金权限。

    四、 C2C 入金买币详解（人民币买 USDT） #

    1. 什么是 USDT？为什么要先买 USDT？ #

    USDT（泰达币） 是锚定美元（1 USDT $\approx$ 1 美元）的稳定币，相当于加密货币世界的“通用筹码”。通过人民币兑换成 USDT 后，你可以使用 USDT 在平台内自由购买比特币（BTC）、以太坊（ETH）等任意币种。

    2. 交易区域选择：快捷区 vs 自选区 #

    在 APP 首页顶部点击 「C2C买币」，可以看到三个区域：

    交易区域 特点 风险与建议
    快捷区 系统自动匹配低价商家 只看价格不看质量，商家风控水平参差不齐，易引发支付账户拦截。
    自选区（推荐） 自行筛选、挑选商家 可主动剔除高风险商户，保障资金与支付账号安全。
    VIP 尊享区 大额交易专属 新手阶段无需关注。

    3. 自选区高品质商家筛选标准 #

    进入自选区，输入预计购买金额（如 1000 CNY），点击右侧筛选图标（漏斗）：

    1. 勾选筛选项： 开启「仅显示无需验证单」与「新手友好委托单」。
    2. 看商家标识： 优先选择带粉色钻石标识的钻石商家，其次选择认证商家。
    3. 看运营数据： 查看商家详情，选择注册时间长（如 1.5 年以上）、总成交量大且成交率高的商家。此类商家交纳保证金较多、账户健康度高。

    4. 支付方式推荐：为何首选“支付宝小号”？ #

    建议优先使用 支付宝 进行付款，尽量避免直接使用银行卡：

    • 风控逻辑优势： 支付宝风控以付款前拦截为主（若对方账号异常会直接阻断付款，避免资金流出）；银行卡风控多为付款后冻结。
    • 隔离风险操作： 建议使用个人的支付宝小号，将资金提前存入余额宝（沉淀 1-2 天）后再进行转账。即使触发风控，影响范围也仅限小号，可保护主银行卡与个人资产安全。

    5. 订单付款与交割规则 #

    1. 选定商家，点击「购买」，输入金额/数量后选择「0手续费购买」。
    2. 点击「获取付款详情」，复制商家的姓名与支付宝账号。
    3. 打开支付宝进行转账，并严格遵守以下规则：
    • 必须实名转账： 必须使用与 OKX 认证姓名一致的支付宝付款，严禁他人代付。
    • 备注栏保持空白： 付款备注框绝对不要填写“买币”、“USDT”、“OKX”等任何敏感字眼，否则可能导致支付账户被封禁。
    • 请勿设置延迟到账。
    1. 完成付款后返回 OKX APP，点击 「我已支付」 通知商家。
    2. 商家确认到账后将放行 USDT，资产即到账。

    五、 资产划转与现货买入比特币 #

    1. 资金划转（资金账户 $\rightarrow$ 交易账户） #

    购买成功的 USDT 默认保存在 「资金账户」 中（仅用于充提币和 C2C），无法直接用于币币交易。

    • 操作步骤： 点击右下角「资产」 $\rightarrow$ 点击「划转」 $\rightarrow$ 选择从 资金账户 到 交易账户 $\rightarrow$ 币种选择 USDT $\rightarrow$ 点击「最大」并确认。

    2. 现货交易买入 BTC（避开高溢价闪兑） #

    注意：请勿使用「闪兑」功能。 闪兑类似于银行柜台换汇，系统给出的固定报价存在较高溢价，成本较高。

    正确现货交易步骤：

    1. 点击底部菜单栏 「交易」 按钮，进入交易界面。
    2. 点击左上角交易对，搜索选择 BTC/USDT。
    3. 交易方向选择 「买入」。
    4. 订单类型切换为 「市价委托」（即以当前市场最优价格立即成交）。
    5. 拖动滑块或输入准备使用的 USDT 数量。
    6. 点击 「买入 BTC」 确认提交，购买完成。

    六、 常见问题解答（FAQ） #

    Q1：注册时忘记填写邀请码，后续可以补填吗？ 不能。 邀请码仅限注册环节填写。若必须享受 20% 手续费返现，只能使用新的电子邮箱和手机号重新注册，并在注册时准确填写邀请码 1912474。

    Q2：C2C 付款后，商家迟迟不放币怎么办？ 首先在订单内的「聊天」窗口联系商家催促。若商家超时未处理或拒不放币，点击订单页面的 「申诉」 按钮，上传付款凭证，平台客服介入后会自动将商家冻结的资产划转给你。

    Q3：为什么买完 USDT 后，交易页面显示余额为 0？ 因为 C2C 购买的币默认存放在「资金账户」。请前往「资产」页面，通过「划转」功能将 USDT 从资金账户转入交易账户即可正常交易。
