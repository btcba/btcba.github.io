    这是购买之前比较重要的一点。

    传统美股中的英伟达股票代码是 NVDA，而 NVDAB 属于股票代币化产品，两者不能简单理解成完全相同的资产。

    可以简单理解为：

    项目 英伟达普通股票 NVDAB 股票代币
    标的 NVIDIA 股票 股票代币化产品
    交易代码 NVDA NVDAB
    交易平台 传统证券市场 加密资产平台相关市场
    持有形式 证券账户中的股票 数字资产形式
    股东权利 按适用规则享有 不应直接等同于普通股票股东权利
    交易规则 证券市场规则 以发行方及交易平台规则为准

    因此，购买前不要只看“价格跟着英伟达股票走”，还应该查看产品说明、发行安排、抵押机制以及适用地区。

    九、NVDAB 怎么下单？ #

    进入 NVDAB 交易页面后，一般需要选择订单类型。

    常见的有：

    限价单 #

    限价单是自己设置一个价格。

    例如当前市场价格是 100 USDT，你可以设置 98 USDT 买入。

    只有市场价格达到你的订单条件时，订单才可能成交。

    优点是价格可以自己控制，但缺点是不一定能够成交。

    市价单 #

    市价单是按照当前市场可成交价格进行交易。

    优点是操作简单、通常能够更快完成成交；但实际成交价格可能受到市场深度和价格波动影响。

    因此，不建议简单地认为“市价单一定更好”。

    如果只是学习操作，可以先使用较小金额熟悉订单界面。

    提交订单之后，可以进入账户资产页面查看。

    资产 → 持仓/现货资产

    十二、买 NVDAB 前需要注意哪些风险？ #

    股票代币化产品虽然操作方式与加密资产比较接近，但仍然存在一定风险。

    1. 价格波动风险 #

    NVDAB 相关价格可能受到英伟达股票价格变化以及市场流动性的影响。

    英伟达股价上涨，并不意味着你在任何时间点都能够按照理想价格卖出。

    2. 流动性风险 #

    不同时间段的买卖盘深度可能不同。

    如果市场深度较低，大额订单可能出现较明显的价格滑点。

    3. 产品风险 #

    股票代币并不应该简单理解为传统券商账户里的普通股票。

    具体资产权益、赎回方式、抵押安排等，都应该查看产品官方文件。

    4. 地区限制 #

    不同国家和地区可能存在不同的产品可用性。

    如果账户页面没有显示 NVDAB，不建议通过其他方式强行使用。

    5. 平台规则变化 #

    交易时间、产品支持范围、费用和最低交易金额等，都可能发生变化。

    因此长期使用时，建议以币安当前页面和公告为准。

    十三、常见问题 FAQ #

    Q1：NVDAB 就是英伟达股票吗？ #

    不是简单意义上的同一种资产。

    NVDA 是英伟达在传统证券市场中的股票代码，而 NVDAB 是股票代币化产品代码。两者在资产形式、交易规则和持有权益方面可能存在差异。

    Q2：买 NVDAB 后是不是就拥有英伟达公司的投票权？ #

    不能这样理解。

    股票代币是否包含投票权、分红相关安排以及其他股东权益，需要根据具体产品的法律结构和官方条款判断。

    购买之前应该查看产品说明，而不是直接按照普通股票的股东权益来理解。

    Q3：NVDAB 的价格会不会跟 NVDA 完全一样？ #

    不一定。

    虽然股票代币通常会参考对应股票资产的价格，但实际交易价格还可能受到市场流动性、交易时间、价差等因素影响。

    因此，不能假设 NVDAB 与 NVDA 在任何时间都保持完全一致的价格。

    Q4：可以买很少的 NVDAB 吗？ #

    是否支持小额交易，要看当前产品的最小交易数量和交易规则。

    如果交易页面允许小数数量或较低的最低订单金额，就可以按照页面要求进行交易。

    Q5：C2C 买 USDT 时应该注意什么？ #

    最重要的是：

    只按照平台订单进行交易，不要脱离平台私下交易。

    付款前认真核对收款信息，并保存付款凭证。如果出现交易争议，通过平台订单页面进行处理。

    Q6：NVDAB 全天都可以交易吗？ #

    不能直接假设 24 小时都可以交易。

    股票代币的交易时间可能受到具体产品规则影响，有些产品可能存在特定交易时段。

    最准确的方式是进入 NVDAB 当前交易页面查看交易状态和官方说明。
