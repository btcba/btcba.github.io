    币安注册教程2026：新用户注册+老用户补填邀请码完整教程 #

    注册的时候忘记填写邀请码怎么办？

    以前注册完成以后没有填写邀请码，基本就只能重新注册，但现在部分符合条件的币安老用户，也可以通过相应的补绑或召回方式尝试建立邀请关系。

    所以这篇文章不只介绍币安新用户注册流程，还会把老用户补填邀请码的方法一起讲清楚。

    本文使用的邀请码：

    币安官方注册入口

    一、币安注册前先判断自己属于哪种情况 #

    如果你还没有币安账户，那么直接按照新用户注册流程操作即可。

    如果你已经有币安账户，但是当初注册时没有填写邀请码，可以先判断自己属于下面哪一种情况。

    用户情况 推荐方式 适合人群
    注册 ≤30天 + 无充值/无买币/无交易 + 无上家 方式一：自助补绑 刚注册忘记填写邀请码的新用户
    不符合方式一 + 近90天交易量≤5,000 USD + 无上家 方式二：重新绑定申请 已有少量交易的存量用户
    注册 >90天 + 过去90天完全无活动 + 无上家 方式三：老用户召回 长时间没有使用币安的老用户

    以上分类按照你提供的活动条件整理。三种方式都有一个非常重要的前提：

    账户目前不能已经存在其他推荐关系。

    也就是说，如果你的账户已经绑定过其他人的邀请码，一般不能直接换成新的邀请码。你提供的图片也明确把“无上家/没有推荐关系”作为三种方式的共同前提。

    二、没有币安账户的新用户怎么注册？ #

    如果你是第一次使用币安，最简单。

    直接进入注册页面：

    币安注册入口

    邀请码：BTC147

    建议新用户在注册的时候就把邀请码确认好，不要等账户注册完成以后再处理。

    第一步：打开币安注册页面 #

    进入币安官方注册页面后，根据当前页面提供的选项选择注册方式。

    一般可以使用：

    • 邮箱
    • 手机号码
    • 页面提供的其他注册方式

    币安官方注册说明目前支持邮箱、手机等方式注册账户。

    第二步：输入邮箱或手机号码 #

    选择注册方式后，输入自己的邮箱或者手机号码。

    建议使用自己长期使用的联系方式，因为以后登录、安全验证以及账户找回都可能使用到。

    第三步：输入验证码 #

    提交邮箱或手机号后，根据页面提示获取验证码。

    收到验证码以后，将验证码填写到注册页面。

    验证码、密码以及2FA验证码不要提供给任何陌生人。

    三、注册时一定检查邀请码 #

    这是整个注册过程中比较重要的一步。

    如果你是通过本文提供的注册链接进入：

    邀请码：BTC147

    正常情况下，推荐关系会随着注册链接进入注册流程。

    注册完成之前，建议再检查一次邀请码是否已经正确关联。

    为什么要特别强调这一点？

    因为币安官方推荐计划规则显示，推荐关系一旦建立，并不是普通用户可以随意修改的。

    所以：

    新用户最好的操作方式就是注册的时候直接绑定。

    不要先注册，之后再考虑邀请码。

    四、设置币安账户密码 #

    接下来根据页面要求设置登录密码。

    建议使用一个专门用于币安账户的独立密码，不要和其他网站使用相同密码。

    密码最好包含：

    • 大写字母
    • 小写字母
    • 数字
    • 特殊字符

    同时不要使用生日、手机号等容易被猜到的信息。

    五、完成币安实名认证 #

    账户注册完成以后，还需要按照币安页面提示完成身份认证。

    进入账户后，根据页面提示找到：

    个人中心 → 身份认证

    不同版本的网页或者 App 页面可能略有不同，以当前页面显示为准。

    实名认证通常包括：

    1. 填写个人资料；
    2. 选择实际居住国家/地区；
    3. 提交身份证明；
    4. 根据要求完成真人识别；
    5. 等待审核。

    一定要填写真实、准确的信息。

    不要为了通过认证而虚构居住地或者使用他人身份资料。

    另外，币安不同地区的产品和服务可能存在限制，最终以你所在地区实际显示的服务为准。币安官方也特别提示，其产品和服务可能并非在所有地区提供。

    如果从来没有绑定过邀请码，再继续判断自己符合哪一种情况。

    • 注册时间；

    十四、常见问题 #

    1、已经注册币安了，还能填写邀请码吗？ #

    部分账户可以。

    但不是所有老用户都符合条件。

    首先需要确认账户有没有绑定过其他邀请码，然后再根据账户注册时间、近期交易量和近期使用情况判断。

    2、注册超过90天还能补邀请码吗？ #

    有可能。

    如果属于注册超过90天，并且过去90天完全没有使用币安产品的账户，可以关注老用户召回计划。币安官方当前召回规则明确包含“账户超过90天”和“过去90天没有交易或使用产品”等条件。

    3、已经绑定别人邀请码还能换吗？ #

    一般不能简单更换。

    因此如果你之前已经存在推荐关系，建议不要反复尝试绑定其他邀请码。

    4、近90天交易量超过5,000 USD怎么办？ #

    按照你提供的活动图片，这种情况不符合方式二的条件。

    至于是否存在其他适用的官方活动，需要以当前账户页面实际显示为准。

    5、刚注册忘记填写邀请码怎么办？ #

    如果注册时间还没有超过30天，并且没有充值、买币、交易，同时没有其他推荐关系，可以优先尝试方式一。
